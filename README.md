# .github

Organization-level GitHub configuration for citature.

- `profile/README.md` — rendered at [github.com/citature](https://github.com/citature)
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md` — org-wide community
  health files. GitHub applies them to every citature repository that doesn't
  carry its own, for public repositories only.
